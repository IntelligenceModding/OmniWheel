## Bug Reports

If you have found a reproducible problem with Omni Wheel, please use the **Bug Report** issue form.

Examples include:

- crashes;
- radial wheel opening or closing problems;
- incorrect wheel selection behavior;
- mouse, click, keyboard, or numpad input problems;
- profile creation, editing, switching, saving, loading, or deletion problems;
- submenu navigation problems;
- command or chat action problems;
- placeholder replacement problems;
- custom shortcut or key conflict problems;
- rendering or interface problems;
- configuration or profile-storage problems;
- compatibility problems;
- other unexpected in-game behavior.

Before submitting a bug report:

- make sure you are using an Omni Wheel version intended for your Minecraft version;
- make sure your mod loader and any required dependencies are compatible;
- check whether the issue has already been reported;
- try to reproduce the problem consistently.

Please include your Minecraft version, Omni Wheel version, mod loader version, relevant dependency versions where applicable, reproduction steps, and logs or crash reports where applicable.

If the problem involves a specific action type, wheel layout, profile, shortcut, placeholder, server, or configuration, include that information as well.

## Feature Requests

Suggestions for new features and improvements are welcome.

Feature requests may include:

- new wheel action types;
- additional client-side utility actions;
- improvements to radial wheel behavior;
- profile-management improvements;
- new placeholders;
- shortcut and input improvements;
- interface or usability improvements;
- configuration improvements;
- compatibility improvements;
- visual improvements;
- other additions that fit the purpose of Omni Wheel.

Please use the **Feature Request** issue form and explain what you would like to see added or changed and why it would be useful.

For larger features, discussing the idea before beginning development is recommended.

## Version Support Requests

Omni Wheel may be maintained across multiple Minecraft versions and mod loaders.

If you would like support for another Minecraft version or mod loader, please use the **Version Support Request** issue form.

Before submitting a request:

- check the available repository branches;
- check the CurseForge project page;
- check the Modrinth project page;
- make sure support for the requested version or loader does not already exist.

Submitting a request does not guarantee that the requested Minecraft version or mod loader will be supported.

## Installation and General Help

GitHub Issues should primarily be used for reproducible bugs, feature requests, and version support requests.

For general questions such as:

- installation help;
- choosing the correct Omni Wheel version;
- dependency questions;
- modpack setup;
- questions about configuring radial wheels;
- questions about profiles or submenus;
- questions about commands, chat actions, placeholders, or shortcuts;
- multiplayer usage questions;
- general usage questions;
- questions that are not confirmed bugs;

please use the Intelligence Modding Discord.

## Security Issues

Potential security vulnerabilities should not be reported through a normal public bug report.

If you believe you have found a security-sensitive issue, report it privately to:

**report AT intelligence-modding DOT de**

Please include enough information to reproduce and understand the issue, including affected versions, reproduction steps, relevant logs, and the potential impact where possible.
