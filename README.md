<p align="center">
  Omni Wheel adds a client-side radial quick-action menu to Minecraft for fast access to commands, chat macros, utility actions, and configurable shortcuts.
</p>

<p align="center">
  Hold a key to open the wheel, select an entry, and trigger frequently used actions without digging through chat, menus, or large collections of individual keybinds.
</p>

<br>

<p align="center">
  <img src="https://raw.githubusercontent.com/IntelligenceModding/OmniWheel/refs/heads/assets/Compatibility.png" alt="Compatibility" height="75">
</p>

<p align="center">
  <img src="https://img.shields.io/badge/Minecraft-1.21.2-3C8527?style=for-the-badge&logo=minecraft&logoColor=white" alt="Minecraft 1.21.2">
  &nbsp;&nbsp;&nbsp;
  <img src="https://img.shields.io/badge/Loader-Fabric-DBD0B4?style=for-the-badge" alt="Fabric">
</p>

<p align="center">
  <strong>Omni Wheel is completely client-side.</strong>
</p>

<p align="center">
  Servers do not need to install Omni Wheel. Profiles, wheel layouts, shortcuts, and tutorial progress are stored locally on the client, allowing the mod to be used in both singleplayer and multiplayer without server-side setup.
</p>

<br>

<p align="center">
  <img src="https://raw.githubusercontent.com/IntelligenceModding/OmniWheel/refs/heads/assets/Features.png" alt="Features" height="75">
</p>

<p align="center">
  Omni Wheel currently includes the following features:
</p>

<p align="center">
  &bull; A hold-to-open radial wheel with mouse selection, click selection, and numpad position bindings<br>
  &bull; Configurable wheel layouts with 1 to 16 segments per wheel<br>
  &bull; Nested submenus for organizing larger setups into specialized wheels<br>
  &bull; Multiple local profiles with in-wheel profile switching and a default starter profile<br>
  &bull; Command entries that can execute one or more commands in sequence when permitted by the current server<br>
  &bull; Chat, open-chat, local-message, and clipboard-copy actions for communication and utility workflows<br>
  &bull; Client-side gameplay actions including hotbar selection, interaction inputs, view toggles, movement toggles, screenshots, screens, and Omni Wheel management functions<br>
  &bull; Per-entry glyphs, colors, GUI colors, visibility settings, and optional custom keyboard shortcuts with conflict checking<br>
  &bull; Placeholder support for values such as <code>{x}</code>, <code>{y}</code>, <code>{z}</code>, <code>{dimension}</code>, <code>{server}</code>, <code>{player}</code>, <code>{profile}</code>, and <code>{gamemode}</code><br>
  &bull; A built-in profile manager for creating, renaming, reordering, editing, and deleting profiles and wheel entries<br>
  &bull; Local JSON profile storage at <code>config/omniwheel/profiles.json</code><br>
  &bull; Guided in-game tutorials for the radial wheel and profile manager
</p>

<p align="center">
  Omni Wheel is designed to make frequently used actions faster and easier to access while keeping configuration flexible and entirely local to the player.
</p>
