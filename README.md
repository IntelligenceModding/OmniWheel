<p align="center">
  OmniWheel adds a client-side radial quick-action menu to Minecraft for players who want fast access to commands, chat macros, utility actions, and profile-based shortcuts.
</p>

<p align="center">
  Hold a key to open the wheel, flick to an entry, and trigger actions without digging through chat or menus. The mod stays focused on configurable client-side workflow tools, while fitting cleanly into both singleplayer and multiplayer play.
</p>

<p align="center">
  <img src="https://raw.githubusercontent.com/IntelligenceModding/OmniWheel/refs/heads/assets/Compatibility.png" alt="Compatibility" height="75">
</p>

<p align="center">
  <strong>OmniWheel is client-side only.</strong>
</p>

<p align="center">
  Servers do not need to install OmniWheel. Profiles and tutorial progress are stored locally on the client, so the mod works in both singleplayer and multiplayer without server-side setup.
</p>

<p align="center">
  <img src="https://raw.githubusercontent.com/IntelligenceModding/OmniWheel/refs/heads/assets/Features.png" alt="Features" height="75">
</p>

<p align="center">
  OmniWheel currently includes:
</p>

<p align="center">
  &bull; A hold-to-open radial wheel with mouse selection, click selection, and numpad position bindings<br>
  &bull; Multiple local profiles, including in-wheel profile switching and a default starter profile<br>
  &bull; Nested submenus so one wheel can branch into specialized wheels for chat, utility, or server-specific actions<br>
  &bull; Configurable wheel layouts with 1 to 16 segments per wheel<br>
  &bull; Command entries that can send one or more commands in order when the current server allows them<br>
  &bull; Chat, open-chat, local-message, and clipboard-copy entries for fast communication and utility workflows<br>
  &bull; Client-side gameplay functions for screens, hotbar selection, interaction inputs, view toggles, movement toggles, screenshots, and OmniWheel management actions<br>
  &bull; Per-entry glyphs, colors, GUI colors, visibility toggles, and optional custom keyboard shortcuts with conflict checking<br>
  &bull; Placeholder support for values such as <code>{x}</code>, <code>{y}</code>, <code>{z}</code>, <code>{dimension}</code>, <code>{server}</code>, <code>{player}</code>, <code>{profile}</code>, and <code>{gamemode}</code><br>
  &bull; A built-in profile manager screen for creating, renaming, reordering, editing, and deleting profiles and wheel entries<br>
  &bull; Local JSON persistence at <code>config/omniwheel/profiles.json</code> plus guided in-game tutorials for the radial and manager
</p>
